LIFT — TRAINING TRACKER

Upload the CONTENTS of this folder to the root of a GitHub repository.
Enable GitHub Pages from Settings → Pages → Deploy from a branch → main → /(root).
Open the published URL in Chrome on your phone, then use Chrome menu → Add to Home screen / Install app.

The app works offline after its first successful load. Workout logs are stored on this device in browser storage. Use Settings → Export backup regularly. Restore a JSON backup from Settings → Restore backup.

The weekly programme is Monday, Tuesday, Thursday, Friday and Saturday training, with Wednesday and Sunday as rest days. Starting weights are references from the numbers supplied by the user; adjust them if technique or effort requires it.
